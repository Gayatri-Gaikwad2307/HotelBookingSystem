# 🏨 Hotel Booking System

A web-based hotel booking application developed using HTML, CSS, JavaScript, and SQLite. The system aims to simplify hotel reservations by providing users with an intuitive interface to explore hotels, check room availability, and manage bookings.

## ✨ Features

- **Hotel Discovery:** Browse and explore available hotels.
- **Room Availability:** Check room availability before booking.
- **Hotel Information:** View hotel and room details.
- **Room Booking:** Make hotel reservations through the application.
- **Database Management:** Store and manage booking-related information using SQLite.
- **Responsive Interface:** User-friendly interface for convenient navigation.

## 🛠️ Technology Stack

| Technology | Purpose |
|---|---|
| HTML5 | Webpage structure |
| CSS3 | Styling and responsive design |
| JavaScript | Client-side functionality and interactivity |
| SQLite | Database management and data storage |

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code (recommended)
- SQLite / SQLite Browser

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Gayatri-Gaikwad2307/HotelBookingSystem.git
```

**2. Navigate to the project directory**

```bash
cd HotelBookingSystem
```

**3. Open the project**

Open the project folder in Visual Studio Code.

**4. Run the application**

Open the main HTML file in your browser or use the VS Code Live Server extension.

> Note: If the project uses a backend to connect JavaScript with SQLite, start that backend separately according to its configuration. Browser JavaScript cannot directly access a local SQLite database.
